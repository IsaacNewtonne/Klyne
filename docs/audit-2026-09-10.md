# Harness continuation audit — 2026-09-10

Targeted review of Studio app access and the self-improvement execution path.
Existing uncommitted Studio, browser, provider and delegation work was preserved.

- Replaced the rejected `access.apps` flag with a Local APIs switch and working
  `app_connect`, `app_list`, and `app_call` tools. Reusable definitions use SQLite;
  calls have loopback scope, deadlines, response limits and durable chat evidence.
- Connected `self_improve` to the existing isolated worktree runner under the
  Terminal grant; reviewers cannot mutate repositories or call app endpoints.
- Fixed promotion of equally failing suites, successful commands with no test
  summaries, empty test suites, and candidates that lose passing tests.
- Validated experiment IDs and Git branch names before constructing worktrees.
- Drained suite output concurrently to avoid pipe-buffer deadlock, bounded capture,
  and bounded reader completion when descendants keep inherited pipes open.
- Added HTTP, permission, connection reuse, model-loop and experiment regressions.

This is not an exhaustive security audit. Desktop and Terminal already provide
broad machine access, but universal app compatibility and automatic installation
remain unimplemented. See [capabilities and limits](local-apps.md).

`workspace/audit-2026-09-10-final.log`. All 170 tests report success; fmt, Clippy
with warnings denied and JavaScript syntax checks pass. Desktop and 390px mobile
screenshots were inspected. PowerShell returned a wrapper error for redirected
Cargo progress on stderr; every libtest result group passed, including doc tests.
